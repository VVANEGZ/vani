# Vani

Vani es mi app para organizar las materias del semestre. La hice porque estaba cansada de instalar aplicaciones gigantes que traen calendario, pomodoro, gráficas de productividad, integración con quince cosas más... y al final solo necesitaba un lugar simple para anotar cosas de cada clase.

Aquí no hay nada de eso. Es minimalista a propósito.

## Qué hace

- Cada materia tiene su propia pestaña.
- Un encuadre que puedes editar y bloquear, para no andar buscando el PDF del profe cada vez que quieres ver cómo se reparten los porcentajes.
- Un calendario dividido en tres categorías: exámenes, proyectos y tareas. Nada de un calendario genérico donde todo se mezcla.
- Bloques de notas por materia, tipo tarjetas, donde puedes escribir libremente (editor con texto enriquecido).
- Le puedes poner un color a cada materia para diferenciarlas rápido.

Sin cuenta, todo se guarda en el navegador. Al iniciar sesión, puedes importar tus apuntes locales y sincronizar materias, encuadre, calendario y notas entre dispositivos con Supabase.

## Por qué así

No quería un Notion, ni un Trello, ni nada con mil funciones que termino sin usar. Quería abrir la app, ver mis materias, escribir lo que necesito y cerrarla. Sin fricciones, sin configurar nada, sin curva de aprendizaje.

Si algún día se siente que le falta algo, probablemente sea porque de verdad hace falta — no porque "otras apps lo tienen".

## Stack

- React
- Tailwind
- TipTap para el editor de texto
- lucide-react para los iconos
